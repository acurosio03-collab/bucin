Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di Chrome/Firefox.
3. Tekan "BUKA SURAT GERDY" untuk memulai perjalanan dan musik.

Catatan:
Musik dibuat tanpa file audio eksternal, sehingga website dapat berjalan offline.
Autoplay dimulai setelah tombol pembuka ditekan, mengikuti kebijakan autoplay browser.
